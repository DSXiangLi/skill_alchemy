# 对话提取方案

## 目标

将不同 CLI 工具的本地 session 转换为统一 JSONL。每行表示一个完整 session，后续流程以 `session_id` 为边界，不跨 session 拼接轮次。

只保留用户真实输入和 AI 最终可见回答；过滤 reasoning、工具调用、工具结果和系统注入。

## 支持的数据源

| 工具 | 默认位置 | 输入格式 |
|---|---|---|
| Kimi Code | `~/.kimi-code/sessions/*/session_*/agents/main/wire.jsonl` | wire events |
| Codex CLI | `~/.codex/sessions/YYYY/MM/DD/rollout-*.jsonl` | rollout events |
| Claude Code | `~/.claude/projects/*/*.jsonl` | message chain |
| Hermes Agent | `~/.hermes/sessions/*.json` | session/request dump |

## 统一输出

```json
{
  "source_tool": "kimi_code | codex | claude_code | hermes_agent",
  "source_file": "/original/session/path",
  "session_id": "stable-session-id",
  "workspace": "/project/path",
  "created_at": "ISO-8601 timestamp",
  "turns": [
    {
      "turn_index": 1,
      "user": "user input",
      "assistant": "final visible answer",
      "timestamp": "ISO-8601 timestamp",
      "interrupted": false
    }
  ]
}
```

`created_at` 必须在提取时固化，不能留给后续流程依赖原始文件 mtime。取值优先级：

1. session/event 中的显式时间戳；
2. 可解析的文件名时间戳，例如 Codex `rollout-YYYY-MM-DDTHH-MM-SS-*`；
3. 提取时读取的源文件 mtime。

## 各工具提取规则

### Kimi Code

- 仅接收 `turn.prompt` 且 `origin.kind=user` 的用户输入。
- 累积当前 turn 的可见 `content.part` 文本。
- `step.end` 或 `turn.ended` 后封闭当前 turn；中断轮次标记 `interrupted=true`。

### Codex CLI

- 使用 `task_started.turn_id` 维护轮次边界。
- 从 `response_item` 的 user message 提取用户文本。
- 优先使用 `task_complete.last_agent_message` 作为最终回答；为空时回退到最后一条 assistant message。
- 排除 environment context、AGENTS.md 和其他系统注入。

### Claude Code

- 接收 `type=user` 且包含真实文本的消息。
- 跳过仅包含 `tool_result` 的 user 消息。
- 累积 assistant content 中的文本块，忽略 thinking 和 tool use。

### Hermes Agent

- 同时支持 `messages` session 格式和 `request.body.input` request dump 格式。
- 按 user/assistant 角色重建轮次。
- 跳过系统注入和无最终回答的空轮次。

## 命令接口

```bash
python3 scripts/extract.py \
  --tool all \
  --min-turns 3 \
  --output output/extracted \
  --format jsonl
```

`--tool` 支持 `kimi_code`、`codex`、`claude_code`、`hermes_agent` 和 `all`。

## 验收标准

- 每个 JSONL 记录只包含一个 session。
- `session_id`、`source_tool`、`source_file`、`created_at` 均非空。
- `turn_index` 在单个 session 内单调递增。
- 系统注入和工具结果不进入用户文本。
- 输出可以直接由 `distill.py` 加载。
